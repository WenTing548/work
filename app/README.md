# 拾光集 · 校园二手交易平台（可运行演示版）

这是配套《软件工程》实验报告的本地可运行演示系统，不是只有界面截图。

## 打开方式

直接双击 `index.html`，或双击 `start.bat`。

建议使用 Edge / Chrome。不需要安装后端、数据库或 Node.js。

## 演示账号

| 角色 | 用户名 | 密码 | 用途 |
|---|---|---|---|
| 学生 | `student1` | `123456` | 浏览、发布、下单、支付、收货、评价 |
| 学生 | `student2` | `123456` | 作为另一名卖家/买家参与交易 |
| 运营 | `admin` | `admin123` | 审核物品、查看全部订单 |

## 已实现的可操作流程

- 学生注册 / 登录 / 学籍认证状态展示
- 首页浏览、分类筛选、关键词搜索、物品详情、物品履历
- 发布闲置 → 运营审核 → 审核通过自动上架
- 下单锁定物品 → 30 秒未支付自动取消
- 模拟钱包支付 → 平台托管 → 卖家确认交付 → 买家确认收货 → 放款
- 订单列表、订单详情、交易进度、买卖双方视角
- 买家评价（星级 + 文字）
- 钱包余额、模拟充值、资金流水
- 运营后台：待审核队列、全部物品、全部订单、成交额统计

## 说明

- 数据保存在浏览器 `localStorage`，刷新页面不会丢失。
- 支付是模拟钱包，不接入真实资金通道。
- 没有真实图片上传，物品封面按分类显示，避免演示环境依赖对象存储。
- 在“我的 → 重置演示数据”可以恢复初始数据。
